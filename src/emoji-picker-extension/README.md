# 우클릭 이모지 피커 (Chrome / Edge / Whale 확장 프로그램)

텍스트 입력창에서 **우클릭** → 이모지 피커가 뜨고, **한국어로 검색**해서 커서 위치에 바로 넣을 수 있어요.

- `해` → ☀️ 🌞 🌻 🌅 …
- `눈물/울음` → 🥲 🥹 😢 😭 😿 💧 … (`/` 또는 `,` = "또는", 띄어쓰기 = "그리고")
- `슬퍼`, `울다`, `ㅋㅋ`, `ㅠㅠ`, `축하`, `하트`, `cry`(영어) 등 활용형·구어체·영어도 검색됨

## 설치 (1분)
1. 이 폴더(`emoji-picker-extension`)를 PC에 저장 (zip이면 압축 해제)
2. 크롬 주소창에 `chrome://extensions` (엣지: `edge://extensions`, 웨일: `whale://extensions`)
3. 오른쪽 위 **개발자 모드** 켜기 → 이 폴더를 확장 프로그램 페이지 위로 **끌어다 놓기**
4. (선택) 로컬 HTML 파일(file://)에서도 쓰려면: **세부정보** → **파일 URL에 대한 액세스 허용** 켜기

이미 열려 있던 탭에도 자동 적용돼서 새로고침이 필요 없어요.
업데이트할 땐 폴더 내용을 덮어쓴 뒤 확장 카드의 ↻(새로고침) 버튼만 누르면 됩니다.

## 사용법
| 동작 | 방법 |
|---|---|
| 피커 열기 | 입력창에서 우클릭 → 메뉴의 **😀 이모지 넣기** |
| (선택) 우클릭 즉시 피커 | 확장 아이콘에서 모드 변경. 이때 원래 메뉴는 Shift+우클릭 |
| 키보드로 열기 | 기본 단축키 없음 (`chrome://extensions/shortcuts`에서 지정 가능). Windows 프로그램을 쓰면 `Ctrl+Win+.` |
| 넣기 | 클릭 또는 방향키 + Enter |
| 여러 개 연속 넣기 | Shift+클릭 / Shift+Enter |
| 닫기 | Esc 또는 바깥 클릭 |

툴바의 확장 아이콘을 누르면:
- 같은 피커가 열리고, 고른 이모지는 **클립보드에 복사**됩니다 → 메모장·카톡·워드 등 **브라우저 밖 프로그램**에 Ctrl+V
- "우클릭 = 바로 이모지 피커" 모드로 바꿀 수 있어요 (원래 메뉴는 Shift+우클릭)

## 동작 안 하는 곳
- `chrome://` 페이지, 크롬 웹스토어 (브라우저 정책상 확장 불가)
- Google Docs처럼 자체 캔버스로 그리는 편집기 → 확장 아이콘(복사) 또는 `Ctrl+Shift+.` 대신 붙여넣기 사용
- 비밀번호·숫자 입력칸은 일부러 제외

## 데이터 갱신
검색어는 유니코드 CLDR 한국어 주석(emojibase-data)에 구어체 표현을 보강한 것입니다.
`tools/build-data.js` 안의 `EXTRA`에 원하는 검색어를 추가한 뒤:
```bash
npm pack emojibase-data && tar xzf emojibase-data-*.tgz
node tools/build-data.js ./package
```
